# Brand logos

Put official brand logo files here, only with the brand's permission
(most brands offer them on a press or media page).

Name each file after the brand in lowercase, spaces become dashes,
as .svg (best) or .png with a transparent background:

gazelle, batavus, cortina, giant, trek, cube, merida, scott, cannondale,
focus, stevens, greens, conway, sparta, gazelle, reany, huyser, superior,
pegasus, tenways, bulls, victoria, vyber, brinckers, bsp, qwic, dutch-id,
kalkhoff, vanmoof, cowboy, fiido, engwe, urban-arrow, decathlon, swapfiets,
alpina, puky, woom, onesport, denver, samebike, fafrees, de-twee-wielen,
marktplaats, facebook-marketplace, bike-totaal-used-bikes,
decathlon-used-bikes, upway-refurbished-e-bikes

Example: img/logos/gazelle.svg
The app picks a file up automatically; no code change needed.
